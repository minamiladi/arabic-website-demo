# Arabic website version (demo project)

A portfolio sample: a static copy of a law firm's WordPress site after adding a full Arabic version (right-to-left layout, Arabic font, language switch on every page, Arabic SEO and an Arabic landing page).

- **Demo project.** "Lantern Gate Advocates" (بوابة الفانوس), its people, phone number and address are fictional. It is not a real company.
- **Forms are demo-only.** Sending a form shows a message and sends nothing.
- Every page is marked `noindex`, so search engines do not list it.

Live copy: https://minamiladi.github.io/arabic-website-demo/
